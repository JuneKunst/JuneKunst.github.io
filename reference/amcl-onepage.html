AMCL 한 장 복습표

저장된 2D 지도에서 위치·방향 (x,y,θ)을 입자로 추정한다.

세 단계

  1. 예측: odom 이동과 잡음으로 가설을 움직인다.
  2. 관측 갱신: 지도와 scan의 일치도로 가중치를 바꾼다.
  3. 재표본화: 가중치에 따라 다음 입자 집합을 뽑는다.

Adaptive

KLD-sampling은 표본 근사 오차·분포가 차지한 상태 구간과 설정 등에 따라 입자 수를 조절한다.

TF 연결

map → odom: 저장 지도 주행의 AMCL 보정
odom → base: 연속적인 odometry 이동
base → sensor: 센서 장착 변환

Nav2 AMCL은 odom→base TF에서 이동 변화를 얻는다. frame 이름·관측 시각·발행 책임을 확인한다.

파라미터 네 묶음

  • 가설 수: min_particles / max_particles
  • 이동 잡음: 차동 모델 alpha1–4
  • 관측 거리 오차 폭: sigma_hit
  • 갱신 조건: update_min_d [m] / update_min_a [rad]

진단 순서

지도·초기 위치 → 센서 TF·시간 → odom·운동 모델 → 관측 모델·파라미터 → 계산량.

입자 집중은 정답 보장이 아니며 파라미터가 틀린 지도·TF를 자동 수정하지 않는다.
