Sim 환경과 Lab 환경은 따로 확인한다

Sim 전용 환경

simenv 또는 .venv-isaacsim의 Python으로 상자·카메라 예제를 실행합니다. 기존 Workstation 설치라면 그 설치의 python.bat 또는 python.sh를 사용합니다.

Lab 전용 환경

IsaacLab-6.1 저장소 안에서 uv가 별도 .venv와 의존성을 관리합니다. Sim 전용 venv가 설치됐다고 Lab 환경까지 준비된 것은 아닙니다.

  1. nvidia-smi, Python 3.12, Git, RAM·디스크 여유를 확인합니다. nvidia-smi의 CUDA 표시는 드라이버가 지원하는 수준이며 Python 패키지의 실제 CUDA 버전을 직접 보여주는 것은 아닙니다.
  2. 교안은 Sim 6.1.0.0과 torch 2.11.0의 cu130 경로를 사용합니다. pip check는 의존성 충돌 점검이지 렌더링 성공 시험이 아닙니다.
  3. 호환성 검사 앱 → 기본 화면 → 빈 장면 실행 순으로 확인합니다. 첫 실행에는 약관·확장 다운로드·셰이더 준비 시간이 들 수 있습니다.
  4. Lab은 태그와 아래 실제 commit을 맞춘 뒤 uv sync --frozen --extra isaacsim을 실행합니다. 기존 폴더를 덮어쓰거나 uv.lock을 임의로 갱신하지 않습니다.
  5. Lab 환경에서 Sim 버전 6.1.0.0과 Isaac-Cartpole 목록을 확인한 뒤 실제 환경 step·학습을 시험합니다.

공식 자료와 추가 대조 · 별도 환경의 CUDA 선택

Sim 6.1의 독립 pip 환경은 공식 문서에서 torch 2.11의 cu128·cu130 선택지를 제공하므로 교안의 cu130 선택은 유효한 경로입니다. 반면 위 Lab EA commit의 uv 설정은 Windows·Linux x86_64에 cu128, Linux aarch64에 cu130을 매핑합니다. 같은 버전의 Sim을 사용해도 두 환경의 의존성 선택이 같다고 가정하거나, Lab lockfile을 standalone 설정에 맞춰 바꾸지 않습니다. Sim 공식 Python 설치 · EA pyproject.toml

왜 “Sim 모듈 없음”이 나오면 재설치부터 하지 않을까?

실제로 실행한 Python 경로가 다른 환경을 가리킬 수 있습니다. 작업 폴더, Python 실행 파일, 설치된 패키지 버전을 먼저 확인하면 중복 설치를 줄일 수 있습니다.

3 / 8 · 교안 12–15쪽 · 이전 수업: 물리·단위·측정

질량이 10배면 먼저 떨어질까?

공기 저항을 무시하고 같은 중력·초기 높이·초기 속도로 놓으면, 자유낙하 가속도는 질량에 의존하지 않습니다. F = mg와 F = ma에서 a = g가 되기 때문입니다. 실제 Sim에서는 접촉·시간 간격·초기 조건과 solver 설정도 확인해야 합니다.

위 도식은 접촉면 높이 0, 상자 반높이 0.25 m, 초기 속도 0을 가정한 이상적 계산입니다. 실제 예제 코드를 실행한 결과가 아닙니다. 높이 축은 선택한 시작 높이에 맞춰 정규화합니다. 공기 저항·회전·충돌 후 튐은 생략합니다.

z(t) = z₀ − ½gt². 첫 바닥 접촉의 이상적 시간은 √[2(z₀ − 반높이)/g]입니다. 같은 상자에서 높이를 높이면 더 오래 걸리고, 중력을 줄여도 더 오래 걸립니다.

실제 CSV에서 확인할 것

  • 기본·--height 4·--gravity 1.62를 한 번씩 순서대로 실행하고 조건별 폴더를 보관합니다.
  • heights.csv의 물리 시각을 사용합니다. 교안의 600회 앱 업데이트를 곧바로 물리 시간 600 step으로 단정하지 않습니다.
  • 교안은 중심 z ≤ 0.27 m인 첫 행을 접촉 근사 시각으로 비교합니다. 상자의 크기·바닥 높이·샘플 간격에 의존하는 기준이지 모든 물체의 보편적 접촉 판정은 아닙니다.
  • 바닥 위 상자의 중심은 0이 아닙니다. 바닥이 0이라면 회전하지 않은 상자의 중심은 대략 반높이 위에 놓입니다.

산출물: initial_scene.usda는 시작 장면, heights.csv는 시간에 따른 관측입니다. 시작 장면만으로 낙하 결과까지 알 수는 없습니다.

5 / 8 · 교안 19–20쪽 · 이전 수업: 보상과 목표

점수가 높다는 것과 목적 달성은 다르다

거리 변화 Δd = 이전 거리 − 현재 거리는 접근할 때 양수입니다. 교안의 계산식은 r = 2Δd − 0.01dt + 도착/충돌 항입니다. 접근량은 m, dt는 s로 입력합니다.

0.2 m 접근했다가 0.2 m 후퇴하면?

각각 0.1초라면 0.399 + (−0.401) = −0.002입니다. 순수 거리 변화는 상쇄되고 시간 비용이 남습니다. 할인·종료·다른 보상 항이 있으면 실제 누적 보상 분석은 그 조건을 포함해야 합니다.

도착 보상을 계속 받거나 충돌 벌점이 작으면?

도착 상태에서 보상을 반복 수집하거나 충돌을 감수하는 편법을 배울 수 있습니다. 도착 보상을 주는 사건과 종료 조건을 정하고, 보상과 별도로 성공률·충돌률·시간을 측정해야 합니다.
