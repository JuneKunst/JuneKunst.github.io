Archify 3.2.0 원본 standalone HTML을 그대로 배포합니다. 이미지 변환이 아닙니다. 노드 선택·검색·방향성 경로 추적·렌즈·확대·테마·모션 기능을 포함합니다. iPad는 Safari 가로 화면을 권장합니다.

118개 구성 요소와 195개 관계를 포함하며, 모든 상자가 ROS 노드는 아닙니다. feature/mission-v5-sim 작업 트리 스냅샷을 바탕으로 현재 구현과 cuVSLAM 적용 예정 구조를 구분합니다. cuVSLAM은 사용할 계획이며 점유 격자 공급·지도 서비스 연계는 후속 구현입니다.

원본 로컬 프로젝트 코드, Git 저장소, 개인 설정 및 로컬 서버 설정은 배포하지 않습니다. 검증 출처의 로컬 스냅샷 해시는 팀 원격 저장소 커밋이 아닙니다. 로컬 전용 코드 참조는 공개 파일 링크로 제공하지 않습니다.

업데이트 시 index.html만 교체하고 날짜별 HTML은 보존합니다. 출처·구성 수정은 Archify candidate에서 생성한 뒤 검증하고 배포합니다. manifest.json은 게시된 HTML 해시와 자료 범위를 기록합니다.
